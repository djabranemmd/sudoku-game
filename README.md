# 🧩 Sudoku Game (Browser Project)

---

## 🇬🇧 English Version

### 🎮 About the Project

This is a **Sudoku game built using HTML, CSS, and JavaScript** that runs directly in the browser.

The goal of the project is to practice:

- JavaScript logic
- DOM manipulation
- Game development basics
- UI/UX design for web apps

---

### ✨ Features

- 🧠 Sudoku grid 9×9
- 🎨 Professional UI with 3×3 bold borders
- ⚡ Real-time validation (row, column, box)
- 🔴 Error highlighting
- ⏱️ Timer system
- 🎚️ Difficulty levels (Easy / Medium / Hard)
- 🔄 Reset game
- 🆕 New puzzle generation
- 🏆 Win detection system

---

### 🛠️ Technologies Used

- HTML5
- CSS3 (Grid Layout)
- JavaScript (Vanilla JS)

### 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/djabranemmd/sudoku-game.git"
```

2. Go to project folder:
```bash
cd sudoku-game
```
3. Open index.html in your browser.
